# **Zero Point - Операцеонная Система**
**На данный момент Zero Point находится в активной стадии разработки** 

**ZeroPoint предназначена только для AArch64 и ARMv8. Поддержка ARMv7< и ниже, а так-же AArch32 не планируется** \
**ОС работает пока только на Raspberry Pi4** 

Версия ОС - 0.0.3(pre-alpha)

# **Возможности ОС**
Выводит текст в консоль через **UART**, так-же обрабатывает ввод с клавиатуры \
Обрабатывает прерывания через **GIC** \
Имеется поддержка **GICv2/3**

# **Важная деталь**
**Zero Point - полностью зависит от прошивок: ZeroPointFirmware**\
[**Скачать прошивки можно от сюда**](https://github.com/Operator-about/ZeroPointFirmware)

# **Сборка:**
Проект собирается через компилятор - **aarch64-none-elf-** \
ОС собирается изначально в файл *.elf*. Для перевода его в *.img* используется - **aarch64-none-elf-objcopy** \
Для сборки используется **CMake**
